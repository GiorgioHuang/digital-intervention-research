## 2. Review-State Vocabulary

| Review State | Meaning |
|---|---|
| Reviewed | No document-specific blocking inconsistency identified in this review. |
| Reviewed with Open Issue | A non-blocking correction or clarification remains. |
| Reviewed with Blocking Conflict | The document conflicts with another authoritative baseline and requires amendment. |
| Reviewed — Contingent | Internally coherent, but relies on an unresolved upstream domain or contract decision. |
| Reviewed — Draft | Reviewed for consistency, but formal governance or ethics approval remains pending. |
| Revalidation Required | An upstream authority changed; the document must be checked and, if necessary, revised before contract freeze. |
