# UI_INVENTORY

> The list of interfaces that need designing. Frame of reference: Doc 20 v1.3 (Conceptual Prototype UX & Design System, 330 sections) is the source of specification; this file converts it into **deliverable design units** and states each one's current implementation status honestly.
